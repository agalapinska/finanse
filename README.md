# Finanse domowe

Osobisty dashboard finansów domowych: budżet, długi metodą lawiny, poduszka i cele.

Jeden plik HTML, bez backendu. Dane zapisują się wyłącznie w przeglądarce użytkownika (localStorage) i w plikach JSON, które sam zapisuje i wczytuje — w tym repozytorium nie ma żadnych danych finansowych.

Strona: https://agalapinska.github.io/finanse/
